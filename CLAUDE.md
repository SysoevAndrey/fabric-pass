# Fabric Pass

## Ideas registry

`ideas/ideas.md` tracks project ideas and who is working on what. Before starting
any substantive work: `git pull`, find the idea there, check its status and owner —
the `ideas` skill (`.claude/skills/ideas/SKILL.md`) has the full protocol. Claiming
an idea means setting `**status:** in-progress · **owner:** <your GitHub login>` in
its metadata line, committing that change alone, and pushing immediately. Don't start on an idea someone else owns without talking to
them first.
